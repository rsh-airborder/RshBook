# RshBook 日系笔记本主题与更新时间设计

## 目标

将现有默认 VitePress 文档视觉改造成更有个人感、适合长期阅读的日系笔记本风格，并在普通内容页显示自动计算的最后更新时间。

## 方案选择

采用 VitePress 原生主题扩展：通过配置和自定义 CSS 覆盖视觉变量与既有页面元素。

不引入第三方主题或运行时插件。这样保留当前导航、侧栏和 Markdown 写作方式，减少依赖和后续维护成本。

## 视觉系统

- 背景采用暖米白，正文采用深墨色，分隔线使用浅灰褐色。
- 朱红作为有限的强调色，用于链接、当前导航和局部装饰。
- 标题使用具有书写感的衬线字体回退栈，正文保持易读的系统无衬线字体。
- 首页延续“留白，留住想法”的日系笔记本方向；文章页保持宽松的行距和克制的装饰。
- 顶栏、侧栏和文章区域以细分隔线与留白组织信息，避免默认技术产品网站观感。

## 最后更新时间

- 在 VitePress 配置中启用 Git 提交时间读取。
- 在主题配置中将标签设置为“最后更新”。
- 所有普通 Markdown 页面在正文底部显示日期，格式遵从站点的中文区域设置。
- 首页采用 home 布局，不显示更新时间。

## 文件边界

- `docs/.vitepress/config.mts`：开启最后更新时间及对应中文标签。
- `docs/.vitepress/theme/index.ts`：加载 VitePress 默认主题和本站样式。
- `docs/.vitepress/theme/style.css`：仅负责颜色、字体、间距及默认主题组件的视觉覆盖。
- `.gitignore`：排除本次视觉方案预览生成的 `.superpowers/` 临时文件。

## 验证

1. 执行 `npm ci && npm run docs:build`，确保构建成功。
2. 本地预览普通文章页，确认可见“最后更新”及日期。
3. 本地检查首页不显示更新时间，并检查暖米白、朱红强调和导航样式。
4. 推送至 `main` 后确认 GitHub Actions 成功，并打开 GitHub Pages 复核线上样式。
